# Source-data rights and attribution

Imported zone geometry is reproduced by permission: the World of Surf project
operator expressly confirmed redistribution permission and requested public
downloads and this draft contribution on 25 Nov 2026. This is not a claim that
World of Surf authored every zone or owns all source data.

Original authorship, existing notices and applicable source terms are retained.
This import does NOT newly dedicate third-party native or converted zone data to
the public domain, and does not assume the upstream repository's Unlicense
automatically licenses unrelated input data. Upstream's original LICENSE and
existing files are unchanged. Maintainers should confirm the source-data terms
are acceptable before promoting proposals into their deployed z/ collection.

Source: the publicly published World of Surf native-zone collection, containing
Momentum/community and curator-authored data. Original native bytes and metadata
are retained in the native archive; per-file URLs, hashes and catalogue source
fields accompany the reports. Missing original author names are not invented.
The converter was written for World of Surf; no Shavit/Valve program code, BSPs,
models, textures, private user maps, editor drafts, account records or credentials
are included. This is a data-only proposal, not a SourcePawn code import.
